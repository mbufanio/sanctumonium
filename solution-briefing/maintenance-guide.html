Solution Briefing

Maintenance & Presenting Guide

How to keep the briefing deck up to date, present it, and export a copy — the everyday essentials for the team. No coding required.

For the solution-briefing/ web deck  ·  No coding experience assumed

1. The basics — the files & how to make an edit

The whole deck is just three text files plus a folder of images — you don't need any special software to keep it current. You can edit all of them in any plain-text editor. VS Code (free) is ideal, but even Notepad/TextEdit works. Open the solution-briefing folder and you'll see:

FileWhat lives hereHow often you'll touch it
index.htmlAll slide text and content — one <section> block per slideEvery content change
styles.cssAll colors, fonts, and sizes — the brand config is at the very topRarely — brand is already set
deck.jsThe navigation engine (arrow keys)Never — leave it alone
assets/The logo, images, and videosWhen swapping pictures
How to preview your changes

Double-click index.html to open the deck in your browser. After each edit, save the file and press the browser's Refresh (F5) to see it. Keep the editor and browser side by side — edit, save, refresh, repeat.

The golden rule for text edits

In index.html, your text sits between tags like <h1> and </h1>. To change wording, edit only the words between the tags — never delete the <...> tags themselves.

<!-- change the words, keep the tags -->
<h1 class="cover-title">Your headline here</h1>
                       ↑ edit this part only
Find what you need fast

Every slide in index.html starts with a big comment banner you can search for — e.g. SLIDE 3 — SOLUTION OVERVIEW. Use your editor's Find (Ctrl/Cmd + F) to jump straight to the slide you want to edit.

Always back up first

Before editing, copy the whole solution-briefing folder somewhere safe. If an edit ever breaks the look, you can start again from the copy. The safe rhythm is: one small edit → save → refresh → check.

2. Background video & animation

The cover slide is already wired for a background video. To use or swap it:

1
Put your clip in the assets folder, named assets/cover-bg.mp4 (MP4, H.264 — export "web/1080p" from any editor). Keep it short and looping.
2
Optional: add a still frame assets/cover-poster.jpg that shows before the video loads (and in the PDF export).
3
That's it — it autoplays, muted, looping, behind the text.

To put a background video on another slide, copy these two lines from the cover slide to just inside that slide's <section>, and point to your file:

<video class="slide-bg-video" autoplay muted loop playsinline poster="assets/my-poster.jpg">
  <source src="assets/my-clip.mp4" type="video/mp4" />
</video>
<div class="slide-bg-scrim"></div>   <!-- darkens the video so text stays readable -->
Offline & autoplay notes

Videos must be muted to autoplay. Bundle the actual video file in assets/ (never link a YouTube/CDN URL) so the deck works with no internet. If a video won't play from a double-clicked file, serve the folder locally — see the deck's README.

The moving grid "sensor sweep" behind every slide is pure animation (no file) and already on — nothing to maintain.

3. Exporting a static copy (PDF & PowerPoint)

PDF — easy and faithful (recommended)

1
Open the deck in Google Chrome or Edge.
2
Press Ctrl/Cmd + P.
3
Destination → Save as PDF. Set Margins: None and tick Background graphics.
4
Save. You get one clean slide per page — perfect as a leave-behind or email attachment.

The deck already has a print stylesheet that lays out exactly one slide per page and reveals all animated elements. Video backgrounds can't appear in a PDF, so the poster image / dark background shows instead — that's why a cover-poster.jpg is worth adding.

PowerPoint (.pptx) — the honest caveat

Read this before promising a .pptx

A rich, animated web deck cannot be converted into an equally-rich, editable PowerPoint. Videos, animations, and custom layouts do not round-trip into editable PowerPoint shapes. There is no lossless "Save as PPTX."

Two realistic options:

  • Best for handouts: use the PDF above. It opens everywhere, looks identical, and needs no PowerPoint.
  • If a .pptx is truly required (e.g. to paste slides into a corporate template): export the PDF, then in PowerPoint insert each PDF page in as a picture, or open the PDF in a converter. You'll get one image per slide — not editable text, but it drops into any template. This is a fallback, not a primary workflow.

The recommendation: present from the live web deck (that's where the videos and animation shine), and hand out the PDF.

You can also click the right or left half of the screen to move forward or back, or use the on-screen arrows in the bottom-right. Press F (or the ⛶ button) for fullscreen before you present.

On a company website (for easy access)

Upload the whole solution-briefing/ folder to any static web host — your company web server, an S3 bucket, SharePoint, Netlify, or GitHub Pages. There's no server-side code, so "hosting" is just copying files. Share the link; it opens in any browser.

On a laptop with no internet (trade-show floor)

Copy the same solution-briefing/ folder onto the laptop (or a USB stick). Double-click index.html. Because every font, image, and video is bundled in the folder, it runs fully offline — identical to the hosted version.

One deck, both modes

The hosted copy and the offline copy are the same files. Keep one master folder, and whenever it's updated, re-upload it to the website and re-copy it to the presenting laptops.

★ One-Page Cheat Sheet — common edits

Everything you need for day-to-day tweaks. index.html = words & pictures. styles.css = colors, fonts, sizes.

Change wording on a slide

In index.html, edit the text between the tags. Keep the tags.

<h3>Your new title</h3>

Change a color (whole deck)

In styles.css, top :root block. Change the 6-char hex.

--brand-accent: #e2231a;
--brand-primary: #101820;

Font color of one piece of text

Wrap it and add an inline color (in index.html):

<span style="color:#e2231a">text</span>

Or use the built-in accent: <span class="accent">text</span>

Background color of a slide

Whole deck: change --brand-primary. One slide only — add to that <section>:

<section class="slide" style="background:#101820">

Bigger / smaller font

One item — add an inline size (in index.html):

<h2 style="font-size:3rem">...</h2>

A whole class of text: change its size variable in styles.css, e.g. --size-section-title.

Bold / italic / underline

<strong>bold</strong>
<em>italic</em>
<u>underlined</u>

Wrap the words you want to style. They can nest: <strong><em>both</em></strong>.

Change a picture / logo

Drop the new file in assets/, then point to it in index.html:

<img src="assets/my-photo.jpg" />

Or just overwrite assets/logo.svg with a file of the same name.

Change the font

In styles.css :root block:

--font-heading: "Arial Black", sans-serif;
--font-body: "Georgia", serif;

Add / delete / move a slide

Copy, delete, or move a whole block from <section> to </section>.

<section class="slide">
   ... slide content ...
</section>

Change a bar-chart bar

Height = the --h percentage (on the proof slide, index.html):

<div class="bar" style="--h: 72%">

Highlight a word in accent color

<span class="accent">wins</span>

Uses your --brand-accent color automatically.

Export to PDF

Open in Chrome → Ctrl/Cmd+P → Save as PDF → Margins None, tick Background graphics.
